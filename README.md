# Deadlock Quote Flipper
____________________________________________________________________
I really love Deadlock, so I figured it would be cool to make a voice line quoter thing. 
The code has the corresponding characters face-cards with their voicelines. **you should play the voice lines, they are awesome**.

## Requirements Met
____________________________________________________________________

+ Created an array of 8 quotes (text, author/character)
+ Added a container element and quote button
+ Used ```document.querySelector```
+ Attached click event with ```addEventListener```
+ On page load, there is a quote shown automatically
